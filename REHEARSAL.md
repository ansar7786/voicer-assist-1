# Rehearsal & Demo Checklist

This document tracks rehearsal procedures and demo day requirements.

## Pre-flight Checklist

- [ ] Headphones connected (mandatory to avoid audio feedback loop)
- [ ] Internet connection verified (and backup phone hotspot ready)
- [ ] Backend running (`uvicorn backend.main:app --port 8000`)
- [ ] Frontend running (`npm run dev`)
- [ ] `.env` loaded with valid `GEMINI_API_KEY` and `GEMINI_LIVE_MODEL`
- [ ] Health check verified: `GET http://localhost:8000/api/health`
